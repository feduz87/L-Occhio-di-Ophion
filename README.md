# L'Occhio di Ophion

Un GDR fantasy a turni per browser, ambientato nelle nebbie di Brumafonda. Scegli un eroe, affronta creature sempre più forti, guadagna esperienza e cerca di sopravvivere.

## Avviare il gioco

Apri `index.html` in un browser moderno. Non sono necessarie installazioni, server o dipendenze: il prototipo usa HTML, CSS e JavaScript standard.

## Come si gioca

- Scegli nome e classe: Cavaliere, Arcanista o Ranger.
- A ogni turno puoi attaccare, parare il prossimo colpo o usare una delle tue pozioni.
- Sconfiggi i nemici per ottenere esperienza e salire di livello; la salute e la forza crescono con te.
- Quando la salute finisce, ricomincia l'avventura e prova un nuovo cammino.

## Spunti per svilupparlo

- Aggiungere una mappa con bivi narrativi e scelte che cambiano gli incontri.
- Introdurre abilità specifiche per classe e oggetti da trovare o acquistare.
- Scrivere missioni legate all'Occhio di Ophion e ai personaggi di Brumafonda.
- Salvare i progressi e offrire un finale dopo una serie di incontri.
